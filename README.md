# Rahul Travel 🌍

Rahul Travel is a travel booking website with a complete admin dashboard for managing bookings, customers, contact messages, and travel packages.

## ✨ Features

- 🌍 Travel destination website
- 📦 Dynamic travel package management
- 📝 Online travel booking
- 📊 Admin dashboard
- 🔐 Secure admin login
- 📋 Booking management
- 🔎 Booking search and status filtering
- 📄 Booking pagination
- 🗑️ Delete bookings
- 📥 Export bookings
- 📧 Email customer support
- 💬 WhatsApp customer contact
- 📩 Contact Us management
- 🔍 Customer booking status lookup
- 📧 Gmail email integration

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite
- Nodemailer
- Git & GitHub
